## Полное описание

```text
Conspect — конспекты лекций без лишних усилий.

Включите запись перед парой: приложение распознаёт русскую речь офлайн, убирает отступления преподавателя и собирает аккуратный конспект с формулами LaTeX. Готовый конспект можно сохранить в PDF A4, найти в библиотеке или отправить.

• Офлайн-распознавание речи (Vosk). Модель скачивается один раз внутри приложения.
• Локальная обработка по умолчанию: аудио не сохраняется и не покидает телефон.
• Опционально — DeepSeek Flash по вашему API-ключу для более умного структурирования.
• LaTeX-формулы, PDF, поиск, предметы и редактирование.
• Material You, тёмная тема, Google Sans.
• Без рекламы, подписок и регистрации.

Как это работает:
1. Добавьте предмет.
2. Нажмите «Запись» и разрешите доступ к микрофону.
3. Приложение слушает лекцию и показывает живой транскрипт.
4. Остановите запись — конспект появится в библиотеке.
5. При необходимости выгрузите PDF.

Приватность:
Аудио обрабатывается на устройстве и не записывается. Текст отправляется в DeepSeek только если вы сами включили этот режим и сохранили свой ключ. Ключ шифруется через Android Keystore. Подробнее — в политике конфиденциальности.
```

## Объяснение разрешений

**RECORD_AUDIO (микрофон)**
```text
Разрешение нужно для записи и офлайн-распознавания лекции. Аудиопоток обрабатывается на устройстве в реальном времени и не сохраняется в файл. Без микрофона основная функция приложения недоступна.
```

**INTERNET (интернет)**
```text
Разрешение нужно для двух необязательных сценариев: однократной загрузки русской модели распознавания Vosk (~44 МБ) и запросов к DeepSeek, если пользователь сам включил этот режим и добавил API-ключ. В локальном режиме приложение работает без сети.
```

**VIBRATE (вибрация)**

```text
Разрешение нужно для тактильного отклика при нажатиях: вкладки, кнопки записи, карточки и переключатели. Вибрация короткая и умеренная, её можно отключить в системных настройках Android.
```

## Данные и безопасность

| Вопрос | Ответ |
|---|---|
| Приложение собирает персональные данные? | Нет. Аккаунта и серверов разработчика нет. |
| Аудио передаётся или хранится? | Нет. Обрабатывается на устройстве в памяти. |
| Конспекты и транскрипты | Хранятся локально в приватном хранилище приложения. |
| API-ключ DeepSeek | Хранится локально в зашифрованном виде (Android Keystore). |
| Передача третьим лицам | Только текст лекции в DeepSeek, если пользователь явно включил DeepSeek и сохранил ключ. |
| Аналитика и реклама | Отсутствуют. |
| Геолокация, контакты, камера, файлы | Не запрашиваются. |
| Удаление данных | Очистка данных приложения или удаление приложения. Модель также удаляется в «Настройки → Модели». |

## Комментарий для модератора

```text
Вход и регистрация не требуются. Для проверки:
1. Добавьте предмет кнопкой «+» на экране «Предметы».
2. На главной нажмите «Начать запись» и разрешите микрофон.
3. При первом запуске записи приложение скачивает модель Vosk с alphacephei.com (~44 МБ). Нужен интернет только на этот шаг; дальнейшее распознавание офлайн.
4. Остановите запись — откроется конспект. Экспорт PDF сохраняет файл в Downloads/Conspect.
DeepSeek выключен по умолчанию и для проверки не требуется: это необязательный режим со своим API-ключом.
```
