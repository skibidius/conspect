## Полное описание

```text
Conspect — конспекты лекций без лишних усилий.

Включите запись перед парой: приложение распознаёт русскую речь (системный движок Android или офлайн Sherpa GigaAM), убирает отступления преподавателя и собирает аккуратный конспект с формулами LaTeX. Готовый конспект можно найти в библиотеке, отредактировать или при необходимости экспортировать в PDF A4.

• Офлайн-распознавание речи (Sherpa GigaAM). Модель ~230 МБ скачивается один раз внутри приложения.
• Аудио не сохраняется. В режиме Sherpa обработка полностью локальная; системный движок может использовать сервис Android/Google.
• Два движка распознавания: системный Android или Sherpa GigaAM офлайн (качество высокое, модель ~230 МБ).
• Опционально — DeepSeek Flash по вашему API-ключу для более умного структурирования.
• LaTeX-формулы, поиск, предметы и редактирование. Экспорт в PDF — когда нужен файл.
• Material You, тёмная тема, Google Sans.
• Без рекламы, подписок и регистрации.

Как это работает:
1. Добавьте предмет.
2. Нажмите «Запись» и разрешите доступ к микрофону.
3. Приложение слушает лекцию и показывает живой транскрипт.
4. Остановите запись — конспект появится в библиотеке.
5. При необходимости экспортируйте конспект в PDF.

Приватность:
Аудио обрабатывается на устройстве и не записывается. Текст отправляется в DeepSeek только если вы сами включили этот режим и сохранили свой ключ. Ключ шифруется через Android Keystore. Подробнее — в политике конфиденциальности.
```

## Объяснение разрешений

**RECORD_AUDIO (микрофон)**
```text
Разрешение нужно для записи и распознавания речи. Аудиопоток обрабатывается на устройстве в реальном времени и не сохраняется в файл. Без микрофона основная функция приложения недоступна.
```

**INTERNET (интернет)**
```text
Разрешение нужно для загрузки модели Sherpa, системного распознавания (если выбрано) и запросов к DeepSeek, если пользователь сам включил этот режим и добавил API-ключ. В режиме Sherpa приложение работает без сети.
```

**VIBRATE (вибрация)**

```text
Разрешение нужно для тактильного отклика при нажатиях: вкладки, кнопки записи, карточки и переключатели. Вибрация короткая и умеренная, её можно отключить в системных настройках Android.
```

## Данные и безопасность

| Вопрос | Ответ |
|---|---|
| Приложение собирает персональные данные? | Нет. Аккаунта и серверов разработчика нет. |
| Аудио передаётся или хранится? | Приложение не сохраняет аудио. В режиме Sherpa обработка локальная; при системном движке аудио обрабатывается службой распознавания Android/Google. |
| Конспекты и транскрипты | Хранятся локально в приватном хранилище приложения. |
| API-ключ DeepSeek | Хранится локально в зашифрованном виде (Android Keystore). |
| Передача третьим лицам | При системном движке аудио может обрабатываться службой распознавания Android/Google. Текст лекции в DeepSeek — только при включённом DeepSeek. В режиме Sherpa аудио не покидает устройство. |
| Аналитика и реклама | Отсутствуют. |
| Геолокация, контакты, камера, файлы | Не запрашиваются. |
| Удаление данных | Очистка данных приложения или удаление приложения. Модель также удаляется в «Настройки → Модели». |

## Комментарий для модератора

```text
Вход и регистрация не требуются. Для проверки:
1. Добавьте предмет кнопкой «+» на экране «Предметы».
2. На главной нажмите «Начать запись» и разрешите микрофон.
3. При первом использовании Sherpa приложение скачивает модель GigaAM (~230 МБ) с huggingface.co. Для системного движка модель не нужна.
4. Остановите запись — откроется конспект. Экспорт PDF сохраняет файл в Downloads/Conspect.
DeepSeek выключен по умолчанию и для проверки не требуется: это необязательный режим со своим API-ключом.
```
